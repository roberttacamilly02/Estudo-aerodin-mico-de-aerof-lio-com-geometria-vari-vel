# Estudo-aerodin-mico-de-aerof-lio-com-geometria-vari-vel
Plano de projeto é focado no estudo aerodinâmico de aerofólios de geometria variável. Por meio de simulações computacionais em CFD de um flap simples, o trabalho analisa a relação entre sustentação e arrasto. O objetivo é comprovar a eficiência aerodinâmica, a estabilidade de voo e a redução no consumo de combustível.
